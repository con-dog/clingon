# Gists
List your gists and make a new one from a file

## My gists
Lists your gists.

```sh
gh gist list
```

## New gist from a file
> [!WARNING]
> Uploads a file as a gist and prints its link. Gists are secret unless you make them public.

```sh
gh gist create <file> <flags>
```

- `<file>` Which file
- `<flags>` Extra options
  - [ ] `--public` public
