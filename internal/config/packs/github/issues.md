# Issues
List open issues, view one and create a new one

## New issue
> [!WARNING]
> Opens a new issue on this repository, asking for its title and body.

```sh
gh issue create
```

## Open issues
Lists this repository's open issues.

```sh
gh issue list
```

## View an issue
Shows an issue and its comments.

```sh
gh issue view <issue> --comments
```

- `<issue>` Issue
