# Setup
Check your Claude Code install, see its MCP servers and update it

## Check installation
Checks your Claude Code install and settings for problems.

```sh
claude doctor
```

## MCP servers
Lists the MCP servers Claude Code is set up to use, and whether each one connects.

```sh
claude mcp list
```

## Update Claude Code
> [!WARNING]
> Updates Claude Code to its latest version.

```sh
claude update
```
