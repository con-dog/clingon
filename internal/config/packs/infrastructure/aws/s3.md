# S3
List and browse S3 buckets, and sync a folder to one

## List buckets
Lists every S3 bucket in the account.

```sh
aws s3 ls
```

## Browse bucket
Lists what's in an S3 bucket, with readable file sizes.

```sh
aws s3 ls s3://<bucket>/ --human-readable <flags>
```

- `<bucket>` Which bucket
- `<flags>` Extra options
  - [ ] `--recursive --summarize` recursive with totals

## Sync folder to bucket
> [!CAUTION]
> Uploads a local folder to S3, copying only files that are new or changed.

```sh
aws s3 sync <dir> s3://<bucket>/<prefix> <flags>
```

- `<dir>` Which folder
  - (x) `.` this folder
- `<bucket>` Which bucket
- `<prefix>` Prefix
- `<flags>` Extra options
  - [ ] `--dryrun` dry run
  - [ ] `--delete` delete remote files not present locally
