# Software
See your MacOs version, check for updates and install them

## Install all updates
> [!WARNING]
> Installs every available MacOs update. Some need a restart.

```sh
sudo softwareupdate --install --all
```

## Updates available
Lists the MacOs updates you can install.

```sh
softwareupdate --list
```

## Version
Shows which version of MacOs this is.

```sh
sw_vers
```
