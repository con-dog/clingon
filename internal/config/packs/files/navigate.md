# Navigate
Go to a folder, or make one and go into it

## Go to folder
Moves your shell into a folder. It stays there afterwards.

```sh
cd <dir>
```

- `<dir>` Which folder

## Make a folder and go into it
Creates a folder, and any missing parents, then moves into it.

```sh
mkdir -p <dir> && cd <dir>
```

- `<dir>` Which folder
